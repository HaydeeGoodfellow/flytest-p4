# ربات دانلود ویدیوهای یوتیوب برای تلگرام

این ربات به شما کمک می‌کند تا ویدیوهای یوتیوب خودتان را (که کانالتان از دسترس خارج شده) دانلود کنید و مستقیماً در تلگرام دریافت کنید.

## ⚠️ نکات مهم
- این ربات برای **دانلود ویدیوهای خودتان** طراحی شده است.
- برای دانلود ویدیوهای خصوصی یا کانال خود، ممکن است نیاز به **کوکی‌های مرورگر** داشته باشید (راهنما پایین).
- یوتیوب ممکن است در ایران مسدود باشد؛ ربات را روی سرور/VPS خارج از ایران اجرا کنید.
- تلگرام محدودیت حجم فایل دارد (حدود ۵۰ مگابایت برای ویدیو ساده، بیشتر با ارسال به عنوان فایل).
- برای ۲۰۰۰ ویدیو، از ربات برای دانلود تکی استفاده کنید یا اسکریپت bulk را اجرا کنید.
- این کار ممکن است با قوانین یوتیوب مغایرت داشته باشد، اما چون ویدیوهای خودتان هستند و در کشوری بدون قانون کپی‌رایت هستید، هدف بازیابی محتواست.

## نصب و راه‌اندازی

### ۱. پیش‌نیازها
- پایتون ۳.۸ یا بالاتر
- ffmpeg (اختیاری اما خیلی توصیه می‌شود برای ادغام صدا و تصویر)

### نصب ffmpeg:
- **لینوکس (Ubuntu/Debian):**
  ```bash
  sudo apt update
  sudo apt install ffmpeg
  ```
- **ویندوز:** از سایت رسمی ffmpeg دانلود و به PATH اضافه کنید.
- **مک:** `brew install ffmpeg`

### ۲. نصب پکیج‌ها
```bash
pip install -r requirements.txt
```

### ۳. ایجاد ربات تلگرام
1. به [@BotFather](https://t.me/BotFather) در تلگرام پیام دهید.
2. `/newbot` را بفرستید.
3. نام و یوزرنیم انتخاب کنید (مثلاً MyYTDownloaderBot).
4. توکن (Token) را کپی کنید.

### ۴. تنظیم ربات
فایل `bot.py` را باز کنید و در خط:
```python
BOT_TOKEN = "YOUR_BOT_TOKEN_HERE"
```
توکن را جایگزین کنید.

### ۵. (اختیاری) برای ویدیوهای خصوصی/خودتان
اگر ویدیوها خصوصی هستند:
1. در مرورگری که با حساب یوتیوب لاگین هستید، افزونه **Get cookies.txt** یا مشابه نصب کنید.
2. کوکی‌های سایت `youtube.com` را خروجی بگیرید و فایل `cookies.txt` را در همان پوشه `bot.py` قرار دهید.
3. در کد، خط مربوط به کوکی را فعال کنید (توضیح داده شده).

### ۶. اجرا
```bash
python bot.py
```

ربات آماده است! لینک ویدیو یوتیوب را به ربات بفرستید.

## نحوه استفاده
- `/start` : شروع
- لینک ویدیو یوتیوب (مثل https://www.youtube.com/watch?v=xxxx) را بفرستید.
- ربات دانلود می‌کند و ویدیو را برای شما می‌فرستد.
- برای کیفیت بهتر یا حجم کمتر، می‌توانید کد را ویرایش کنید.

## دانلود انبوه (Bulk Download)
اگر ۲۰۰۰ ویدیو دارید:
- از یک پلی‌لیست یوتیوب از ویدیوهای خودتان استفاده کنید.
- یا لیستی از لینک‌ها بسازید.
- اسکریپت جداگانه‌ای برای دانلود محلی پیشنهاد می‌شود (بعداً اضافه می‌کنم یا خودتان yt-dlp را مستقیم اجرا کنید).

مثال دانلود محلی با yt-dlp (بهتر برای حجم زیاد):
```bash
yt-dlp --cookies cookies.txt -f "bestvideo[height<=720]+bestaudio/best" --merge-output-format mp4 -o "%(title)s [%(id)s].%(ext)s" "https://www.youtube.com/playlist?list=YOUR_PLAYLIST_ID"
```

## مشکلات رایج
- **خطای دانلود:** مطمئن شوید اینترنت سرور به یوتیوب وصل است.
- **فایل خیلی بزرگ:** کیفیت را در کد به 720p یا کمتر محدود کنید.
- **نیاز به ffmpeg:** نصب کنید.
- **محدودیت تلگرام:** برای فایل‌های بزرگ، ربات به عنوان Document می‌فرستد.

اگر مشکلی داشتید، جزئیات خطا را بفرستید.
